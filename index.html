File Format Guide & Templates

Edutools seamlessly parses standard .ICS (iCalendar), JSON, and CSV files.

1. .ICS (iCalendar Standard)

BEGIN:VCALENDAR
VERSION:2.0
BEGIN:VEVENT
SUMMARY:CSE-201: Data Structures
DTSTART:20260302T090000
DTEND:20260302T103000
LOCATION:Lab 402
DESCRIPTION:Instructor: Dr. Sarah Connor
RRULE:FREQ=WEEKLY;BYDAY=MO
END:VEVENT
END:VCALENDAR

2. JSON Class Routine

[
  {
    "courseCode": "CSE-201",
    "subject": "Data Structures & Algorithms",
    "dayOfWeek": 1,
    "startTime": "09:00",
    "endTime": "10:30",
    "room": "Lab 402",
    "instructor": "Dr. Sarah Connor"
  }
]

3. CSV Timetable (Headers Required)

CourseCode,Subject,Day,StartTime,EndTime,Room,Instructor
