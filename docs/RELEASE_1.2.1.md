Edutools 1.2.1

- Fixed false update alerts by comparing GitHub releases with the version compiled into the installed app.
- Automatic update checks stay silent when the installed version is equal to or newer than the latest release, or when no valid release can be checked.
- Build metadata no longer changes version ordering.
- Prevented overlapping update checks from showing duplicate dialogs.

Android version: 1.2.1 (build 121).
