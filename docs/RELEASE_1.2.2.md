Edutools 1.2.2

- Added Section Planner at the end of Tools with a matching drafting icon and card layout.
- Search courses, then find sections by section name, faculty name, or faculty initial.
- Preview a unified Saturday-Friday routine with exact meeting times, red clash indicators, and separate lanes for overlapping classes.
- Keep multiple backup sections per course and switch the active choice before applying the routine.
- Added 791 Fall 2026 BSCSE/BSDS offerings, 1,296 meetings, and 348 faculty suggestions. TBA is displayed as To be announced.
- Clear the previous semester's planner once its configured routine end date passes, while preserving new preparation.
- Added Course Planner code autofill and a blank, searchable instructor input.
- Improved Google sign-in progress, bounded timeouts, and actionable registration/storage errors.
- Improved Drive sync feedback for missing permission, disabled Drive API, and account-sync failures.
- Updated project and backend documentation with setup, permissions, data coverage, and sync behavior.

Android version: 1.2.2 (build 128). Package: com.example.educal.

Install this APK over the existing app. It uses the same package and signing certificate as the previous locally published APKs.

Backup section drafts are local to each device/browser; applied routine classes use normal account/Drive sync. The bundled section data covers CSE/DS Fall 2026 only and does not report live seat availability. Automatic semester cleanup uses the configured routine end date. Google Drive API access, user consent, and a connected MongoDB backend are required for their respective cloud features.
