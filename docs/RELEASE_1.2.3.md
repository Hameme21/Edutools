Edutools 1.2.3

- Automatically fill the assigned instructor when selecting a matching course and section.
- Added section selection to Add/Edit Class, using the Fall 2026 section catalog.
- Retain section identifiers in saved routines and fill missing instructors for matching section-tagged imports.
- Preserve instructor corrections and the existing Edit action for changing class details.
- Keep unknown or ambiguous matches editable instead of guessing an instructor.

Android version: 1.2.3 (build 130). Package: com.example.educal.

Install over the existing Edutools app. This APK retains the same package and signing certificate as the previous published release.

The bundled section catalog covers BSCSE/BSDS Fall 2026 offerings. Faculty entries marked TBA remain To be announced.
